# Compass — Contact a Tutor

A responsive contact form built for **Compass**, a concept student resource
hub for KNUST students. Built for the Elevvo Frontend Web Development Track
(Level 1, Task 2).

## Features
- Split-panel layout: context/stats panel on the left, form on the right
- Fields: Full Name, Email Address, Subject (course), Message
- Fully responsive — stacks to a single column under 860px

## Bonus implemented
- **JavaScript validation**:
  - Full name and subject are required
  - Email is checked against a real email pattern
  - Message must be at least 10 characters
  - Validates on blur (as you tab through fields) and again on submit
  - Focus jumps to the first invalid field on a failed submit
  - Shows a success confirmation banner and resets the form on success

## Tech
HTML, CSS, JavaScript (no frameworks or libraries)

## Run it
Open `index.html` directly in a browser, or serve the folder with the
VS Code "Live Server" extension.
